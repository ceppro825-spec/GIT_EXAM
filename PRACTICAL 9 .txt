AIM:
To create an AI-based web application using Python and Flask,

------------------------------------------------------------
1. UNDERSTANDING THE CONCEPTS
------------------------------------------------------------

What is Docker?

Docker is a platform used to package and run applications in
isolated environments called containers.

What is a Docker image?

A Docker image is a package containing the application code,
libraries, dependencies, and instructions required to run it.

What is a Docker container?

A container is a running instance of a Docker image.

What is a Dockerfile?

A Dockerfile is a text file containing instructions to build
a Docker image.

What is Flask?

Flask is a lightweight Python web framework used to create
web applications and APIs.

What are we building?

We will create an Iris Flower Prediction application.

The user enters four flower measurements:
1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

The machine learning model predicts the Iris flower category.

The application will run at:

http://localhost:5000

3. INSTALL DOCKER ON UBUNTU
------------------------------------------------------------

Step 1: Update package information.

sudo apt update

Step 2: Install required packages.

sudo apt install ca-certificates curl -y

Step 3: Create a directory for Docker's GPG key.

sudo install -m 0755 -d /etc/apt/keyrings

Step 4: Download Docker's official GPG key.

sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

Step 5: Set permissions.

sudo chmod a+r /etc/apt/keyrings/docker.asc

Step 6: Add Docker repository.

sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

Step 7: Update package information again.

sudo apt update

Step 8: Install Docker Engine and related plugins.

sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin -y

Step 9: Check Docker service.

sudo systemctl status docker

If Docker is not running:

sudo systemctl start docker

Step 10: Verify Docker.

sudo docker run hello-world

Expected result:

Hello from Docker!

NOTE:
We use sudo because Docker commands normally require
administrative permission on a fresh Linux installation.

Official installation reference:
https://docs.docker.com/engine/install/ubuntu/

5. CREATE THE PYTHON APPLICATION
------------------------------------------------------------

Step 1: Create app.py.

nano app.py

Step 2: Write the following Python code.

----------------------------------------
FILE: app.py
----------------------------------------

from flask import Flask, request, render_template_string
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier

app = Flask(__name__)

# Load the Iris dataset
iris = load_iris()

# Train the machine learning model
model = RandomForestClassifier(random_state=42)
model.fit(iris.data, iris.target)

# HTML webpage
HTML_PAGE = """
<!DOCTYPE html>
<html>
<head>
    <title>Iris Flower Predictor</title>
    <style>
        body {
            font-family: Arial;
            background: #f2f5f9;
            text-align: center;
            padding: 40px;
        }

        .container {
            background: white;
            padding: 30px;
            max-width: 450px;
            margin: auto;
            border-radius: 12px;
        }

        input {
            width: 90%;
            padding: 10px;
            margin: 8px;
        }

        button {
            padding: 12px 25px;
            background: #2563eb;
            color: white;
            border: none;
            cursor: pointer;
        }

        h2 {
            color: #2563eb;
        }
    </style>
</head>

<body>
    <div class="container">
        <h2>Iris Flower Predictor</h2>

        <form action="/predict" method="POST">

            <input type="number" step="any"
            name="sepal_length" placeholder="Sepal Length" required>

            <input type="number" step="any"
            name="sepal_width" placeholder="Sepal Width" required>

            <input type="number" step="any"
            name="petal_length" placeholder="Petal Length" required>

            <input type="number" step="any"
            name="petal_width" placeholder="Petal Width" required>

            <button type="submit">Predict Flower</button>
        </form>

        {% if prediction %}
            <h3>Predicted Flower: {{ prediction }}</h3>
        {% endif %}
    </div>
</body>
</html>
"""


# Home page
@app.route("/")
def home():
    return render_template_string(HTML_PAGE)


# Prediction route
@app.route("/predict", methods=["POST"])
def predict():

    try:
        values = [
            float(request.form["sepal_length"]),
            float(request.form["sepal_width"]),
            float(request.form["petal_length"]),
            float(request.form["petal_width"])
        ]

        result = model.predict([values])[0]
        flower_name = iris.target_names[result]

        return render_template_string(
            HTML_PAGE,
            prediction=flower_name
        )

    except (ValueError, KeyError):
        return "Please enter valid numerical measurements.", 400


# Run the application
if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)

----------------------------------------

7. CREATE THE DOCKERFILE
------------------------------------------------------------

Step 1: Create a file named Dockerfile.

nano Dockerfile

IMPORTANT:
The filename must be exactly Dockerfile.
Do not add .txt or another extension.

Step 2: Add the following instructions.

----------------------------------------
FILE: Dockerfile
----------------------------------------

# Use Python 3.11 as the base image
FROM python:3.11-slim

# Set the working directory
WORKDIR /app

# Copy requirements file
COPY requirements.txt .

# Install Python dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Copy application files
COPY . .

# Inform Docker that the application uses port 5000
EXPOSE 5000

# Start the Flask application
CMD ["python", "app.py"]

----------------------------------------

Step 3: Save the file.

CTRL + O
Enter
CTRL + X


------------------------------------------------------------
8. UNDERSTANDING DOCKERFILE INSTRUCTIONS
------------------------------------------------------------

FROM:
Specifies the base image.
Here, we use Python 3.11.

WORKDIR:
Sets the working directory inside the container.

COPY:
Copies files from the computer into the image.

RUN:
Executes commands while building the image.
Here, it installs Python dependencies.

EXPOSE:
Documents the port used by the application.
Here, the application uses port 5000.

CMD:
Specifies the command executed when the container starts.

11. RUN THE DOCKER CONTAINER
------------------------------------------------------------

Step 1: Start the container.

sudo docker run -d --name iris-ai-container -p 5000:5000 iris-ai-app

Explanation:

docker run:
Creates and starts a container.

-d:
Runs the container in the background.

--name:
Assigns a name to the container.

iris-ai-container:
Name of our container.

-p 5000:5000:
Maps the computer's port 5000 to the container's port 5000.

iris-ai-app:
Name of the image used to create the container.

Step 2: Check running containers.

sudo docker ps

Expected output should contain:

CONTAINER ID
IMAGE
STATUS
PORTS
NAMES

Our container should show:

IMAGE: iris-ai-app
PORTS: 0.0.0.0:5000->5000/tcp
NAMES: iris-ai-container

16. COMMON ERRORS AND SOLUTIONS
------------------------------------------------------------

ERROR 1: Docker command not found

Reason:
Docker is not installed or the command is unavailable.

Solution:
Install Docker Engine and verify:

docker --version


ERROR 2: Permission denied while connecting to Docker

Reason:
The current user does not have permission to access
the Docker daemon.

Solution:
Use sudo before Docker commands.

Example:

sudo docker ps


ERROR 3: Port is already allocated

Reason:
Another application or container is already using port 5000.

Solution:
Check running containers:

sudo docker ps

Stop the container using that port, or use another host port:

sudo docker run -d --name iris-ai-container -p 5001:5000 iris-ai-app

Open:

http://localhost:5001


ERROR 4: Container starts and immediately stops

Reason:
The application may have encountered an error.

Solution:

sudo docker logs iris-ai-container

Read the error message and correct the application.


ERROR 5: Cannot connect to localhost:5000

Reason:
The container may not be running or the port mapping
may be incorrect.

Solution:

sudo docker ps

sudo docker logs iris-ai-container

Check that port mapping is 5000:5000.


ERROR 6: Docker build fails

Reason:
A missing file, incorrect filename, or dependency error.

Solution:

ls

Check that these three files exist:

app.py
requirements.txt
Dockerfile

Check their contents and run the build again.

17. IMPORTANT VIVA QUESTIONS
------------------------------------------------------------

Q1. What is Docker?

Ans:
Docker is a platform used to package and run applications
inside isolated containers.

Q2. What is a Docker image?

Ans:
A Docker image is a read-only package containing application
code, dependencies, and configuration.

Q3. What is a Docker container?

Ans:
A container is a running instance of a Docker image.

Q4. What is a Dockerfile?

Ans:
A Dockerfile contains instructions used to build a Docker image.

Q5. What is the difference between an image and a container?

Ans:
An image is the package or blueprint.
A container is the running instance created from that image.

Q6. What is the purpose of FROM?

Ans:
It specifies the base image used to build the Docker image.

Q7. What is the purpose of WORKDIR?

Ans:
It specifies the working directory inside the container.

Q8. What is the purpose of COPY?

Ans:
It copies files from the host computer into the image.

Q9. What is the purpose of RUN?

Ans:
It executes commands during image creation.

Q10. What is the purpose of CMD?

Ans:
It specifies the default command executed when a container starts.

Q11. What is port mapping?

Ans:
Port mapping connects a port on the host computer to a port
inside the container.

Q12. What does -p 5000:5000 mean?

Ans:
It maps host port 5000 to container port 5000.

Q13. What is the purpose of EXPOSE?

Ans:
It documents the port the application uses inside the container.
It does not publish the port by itself.

Q14. What is the purpose of -d?

Ans:
It runs the container in detached mode, in the background.

Q15. What is the purpose of docker ps?

Ans:
It displays currently running containers.

Q16. What is the purpose of docker images?

Ans:
It lists the Docker images available locally.

Q17. Why do we use requirements.txt?

Ans:
It lists the Python packages required by the application.

Q18. Why do we use Flask?

Ans:
Flask provides a lightweight framework for creating
web applications and APIs.

Q19. Why do we use 0.0.0.0 in app.run()?

Ans:
It allows Flask to listen on all network interfaces inside
the container, making it accessible through the published port.

Q20. Can multiple containers run from the same image?

Ans:
Yes. Multiple containers can be created from the same image.
